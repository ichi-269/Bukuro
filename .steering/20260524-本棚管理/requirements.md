# 要求仕様: 本棚管理

## 機能概要

ISBN検索で見つけた書籍をユーザーの本棚に追加し、読書状態（読みたい / 読書中 / 読了）を管理する機能。

## ユーザーストーリー

- ユーザーとして、ISBN検索で確認した書籍を本棚に追加したい
- ユーザーとして、自分の本棚に登録した書籍の一覧を確認したい
- ユーザーとして、本棚内の書籍の読書状態（読みたい / 読書中 / 読了）を変更したい
- ユーザーとして、本棚から不要な書籍を削除したい

## エンドポイント

| HTTPメソッド | パス | 説明 | 認証 |
|------------|------|------|------|
| POST | `/books/add` | ISBNで書籍を本棚に追加 | 要 |
| GET | `/shelf` | 本棚一覧表示 | 要 |
| POST | `/shelf/{recordId}/status` | 読書状態変更 | 要 |
| POST | `/shelf/{recordId}/delete` | 本棚から削除 | 要 |

## ビジネスルール

1. 同一ユーザーが同じ書籍を重複登録しようとした場合、エラーを表示して本棚一覧へリダイレクト
2. 本棚追加時、書籍が DB 未登録なら OpenBD から取得して自動登録する
3. 初期状態は「読みたい（WANT_TO_READ）」
4. 読書状態を DONE 以外に変更した場合、評価（rating）は NULL にリセットする
5. 他ユーザーの読書記録は操作不可（ServiceレイヤーでuserIdチェック）

## エラーハンドリング

| エラー | 処理 |
|-------|------|
| 重複登録 | DuplicateRecordException → 本棚一覧へリダイレクト（flashメッセージ） |
| 存在しない recordId | 404エラーページ |
| 他ユーザーのレコード操作 | 403エラーページ |
| OpenBD 未登録の ISBN | ISBN検索画面へ戻してエラーメッセージ（BookNotFoundException） |
