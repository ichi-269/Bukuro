# 要求仕様: 書名で検索する機能

## 背景
現在の書籍登録フローは ISBN 入力のみ対応。ISBNを手元に持っていないユーザーが書名で本を探せるようにする。

## 機能要件

1. `/books/search` ページに書名検索フォームを追加する（ISBN検索と並立）
2. 書名キーワードを入力して検索すると、NDL OpenSearch API を呼び出して候補一覧を表示する
3. 候補一覧には「書名・著者・ISBN」を表示する
4. ユーザーが候補を選択すると、そのISBNで OpenBD API を呼び出して書影を補完する
5. 既存の `book/confirm` 画面をそのまま流用して本棚追加フローに繋ぐ

## 非機能要件

- NDL API はタイムアウト3秒（OpenBDと同等）
- 最大表示件数: 20件
- ISBN のない候補は一覧に表示しない
- 書名検索結果から ISBN を取得し OpenBD で書影補完する際、OpenBD に書誌情報がなければ NDL から取得した書名・著者・出版社を使用する

## スコープ外

- 著者名・出版社名での検索
- 既存の ISBN 検索フローの変更
