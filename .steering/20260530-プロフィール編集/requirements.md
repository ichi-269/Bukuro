# 要求仕様: プロフィール編集

## 背景

PRD の P0 要件「プロフィール（ユーザー名・自己紹介）を編集できる」が未実装。
現在 `user/show.html` には自分のページで「本棚を見る」ボタンしかなく、プロフィール編集への導線がない。

## 機能要件

1. `GET /profile/edit` — 現在のプロフィールを初期値としたフォームを表示する
2. `POST /profile/edit` — ユーザー名・自己紹介を更新して `/users/{username}` にリダイレクト
3. 編集可能フィールド:
   - **ユーザー名** (`username`): 3〜50 文字、英数字・アンダースコアのみ
   - **自己紹介** (`bio`): 任意、最大 500 文字
4. バリデーション:
   - ユーザー名は他ユーザーと重複不可（自分自身と同じ値はエラーなし）
   - ユーザー名が空・短すぎ・長すぎの場合はフォームに戻る
5. `user/show.html` の自分のページに「プロフィールを編集」ボタンを追加する
6. 認証必須（`/profile/edit` は未認証ではアクセス不可）

## 非機能要件

- メールアドレス・パスワードの変更はこの機能のスコープ外
- 既存の `RegisterForm` パターンに準じた DTO・バリデーション設計
