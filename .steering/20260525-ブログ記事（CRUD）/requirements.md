# 要求仕様: ブログ記事（CRUD）

## 機能概要

本棚に登録した書籍に紐づくブログ記事を作成・閲覧・編集・削除する機能。
記事には公開/非公開フラグがあり、公開記事は未認証ユーザーも閲覧可能。

## ユーザーストーリー

- ユーザーとして、本棚の書籍に紐づいた記事を書きたい
- ユーザーとして、自分の書いた記事を編集・削除したい
- 誰でも、公開記事を閲覧したい
- ユーザーとして、非公開記事を草稿として保存したい

## エンドポイント

| HTTPメソッド | パス | 説明 | 認証 |
|------------|------|------|------|
| GET | `/posts/new?bookId={bookId}` | 記事作成フォーム | 要 |
| POST | `/posts` | 記事作成処理 | 要 |
| GET | `/posts/{postId}` | 記事詳細表示 | 不要（公開記事）/ 要（非公開は本人のみ） |
| GET | `/posts/{postId}/edit` | 記事編集フォーム | 要（本人のみ） |
| POST | `/posts/{postId}/edit` | 記事更新処理 | 要（本人のみ） |
| POST | `/posts/{postId}/delete` | 記事削除処理 | 要（本人のみ） |

## ビジネスルール

1. 記事は必ず1冊の書籍（Book）に紐づく
2. 初期状態は非公開（is_public = false）
3. 他ユーザーの記事は編集・削除不可（PostServiceでuserIdチェック）
4. 非公開記事は本人以外閲覧不可（URLを直打ちしても404を返す）
5. 記事の削除は物理削除
6. good_count は今回は 0 固定（グッド機能は別フィーチャーで実装）

## バリデーション

| フィールド | ルール |
|-----------|-------|
| title | 必須、1〜255文字 |
| body | 必須、1文字以上 |
| bookId | 必須（URLパラメータ or hidden field） |

## エラーハンドリング

| エラー | 処理 |
|-------|------|
| 存在しない postId | ResourceNotFoundException → 404 |
| 非公開記事への他ユーザーアクセス | ResourceNotFoundException → 404（存在を隠す） |
| 他ユーザーの記事を編集・削除 | AccessDeniedException → 403 |
| バリデーションエラー | フォームに戻してエラー表示 |
