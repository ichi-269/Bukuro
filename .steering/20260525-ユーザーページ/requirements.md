# 要求仕様: ユーザーページ

## 機能概要

ユーザー名でアクセスできる公開プロフィールページ。
ユーザーの自己紹介と公開ブログ記事一覧を表示する。

## ユーザーストーリー

- 誰でも、`/users/{username}` でユーザーの公開プロフィールを閲覧したい
- 誰でも、そのユーザーが書いた公開記事の一覧を閲覧したい
- ログイン済みユーザーとして、記事タイトルをクリックして記事詳細に遷移したい

## エンドポイント

| HTTPメソッド | パス | 説明 | 認証 |
|------------|------|------|------|
| GET | `/users/{username}` | ユーザーページ（プロフィール + 公開記事一覧） | 不要 |

## 表示内容

| 情報 | 内容 |
|------|------|
| ユーザー名 | `username` |
| 自己紹介 | `bio`（未設定なら非表示） |
| 登録日 | `created_at` の年月 |
| 公開記事一覧 | タイトル・書影・書籍名・グッド数・投稿日（新着順） |
| 記事数 | 公開記事の総数 |

## セキュリティ・アクセス制御

- `/users/**` は SecurityConfig で permitAll 済み（変更不要）
- 非公開記事は表示しない（クエリ側でフィルタリング）
- 存在しない username は 404 を返す

## スコープ外（将来フィーチャー）

- フォロー/アンフォローボタン（フォロー機能は別フィーチャー）
- ページネーション（MVP では全件表示）
