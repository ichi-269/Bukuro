# 読書記録SaaS アイデアメモ

**プロジェクト名候補：** Tsundoku / Shiori / Hondana / Readrift

---

## サービスコンセプト

Spring Boot + OpenBD API を使った、**個人の読書記録を快適にすることを最優先にした**読書ブログ＆本棚サービス。

ISBNを入力するだけで書影・書誌情報が自動取得でき、本の感想をブログ記事のように書いて残せる。
記事は公開・非公開を選べ、公開すれば他のユーザーと読書体験を共有できる。
SNS的な運用も可能だが、あくまで「個人の記録を快適にすること」が設計の軸。

---

## ターゲットユーザー

- 読書好きの 20〜40 代（日本語ユーザー）
- 読んだ本の感想を丁寧に残したい人
- Excel や紙のノートで管理しているが続かない人
- 読書メーターや Notion より、ブログに近い形式で記録したい人
- SNS に感想を流すだけでなく、きちんとアーカイブしておきたい人

---

## 収益モデル（将来）

- 月額 300〜500 円 / 人
- 記録が蓄積されるほど解約しにくくなるストック型モデル
- 読書好きコミュニティへの口コミ・SNS 経由で拡散しやすい

---

## 設計思想・優先順位

1. **個人記録の快適さが最優先** — 非公開で使っても十分価値があるサービスにする
2. **ブログとしての表現力** — 感想をしっかり書ける記事エディタを持つ
3. **SNS機能は補助的** — フォロー・グッド等は「あると嬉しい」程度の位置づけ
4. **シンプルに始める** — 最初は簡易実装でよく、後から拡張する設計を意識する

## 機能一覧

### コア機能（必須・MVP）

| 機能                         | 説明                                                     |
| ---------------------------- | -------------------------------------------------------- |
| ユーザー登録・ログイン       | メールアドレス＋パスワード認証                           |
| ISBN検索 → 書誌情報自動取得  | OpenBD API 連携。タイトル・著者・書影を自動入力          |
| 本棚管理                     | 積読 / 読中 / 読了 のステータス管理                      |
| 星評価                       | 1〜5段階                                                 |
| 読書記録ブログ記事の作成     | 本に紐づいたブログ記事（感想・レビュー）をテキストで書く |
| 公開・非公開設定             | 記事ごとに公開 or 非公開を選択できる                     |
| 自分の記録一覧（本棚画面）   | ステータス別タブで自分の本棚を閲覧                       |
| 自分の記事一覧（マイページ） | 書いた記事の一覧・管理                                   |
| 月別読書冊数グラフ           | Chart.js で読書ペースを可視化                            |

### ソーシャル機能（簡易実装でOK）

| 機能                 | 説明                                               | 初期実装方針                                                                           |
| -------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------- |
| ユーザーページ       | 他ユーザーの公開記事・本棚を閲覧できる             | 公開記事の一覧表示のみ                                                                 |
| フォロー機能         | ユーザーをフォローする                             | フォロー／アンフォローのみ。通知なし                                                   |
| グッド（いいね）機能 | 記事にグッドを押す                                 | カウントを表示するのみ                                                                 |
| ホーム画面           | フォロー中のユーザーの最新記事＋おすすめ記事を表示 | 初期は「フォロー中の記事を新着順」のみ。おすすめは全公開記事からランダム or グッド数順 |

### 対象外（今回は作らない）

- コメント機能
- 記事への画像添付（書影以外）
- 通知機能（フォロー・グッドの通知）
- DM・メッセージ機能
- 多言語対応

## OpenBD API 仕様・利用上の注意

- エンドポイント：`https://api.openbd.jp/v1/get?isbn={ISBN}`
- API キー不要・無料
- レスポンス形式：JSON（配列で返ってくる）
- **利用条件：本の販促・紹介目的に限る** → 読書記録・紹介サービスなので適合
- **データの改変禁止** → タイトル・著者名などをユーザーが編集できる機能はNG
- **削除要請への対応** → 管理画面から書誌データを削除できる実装が必要
- 書影URLは変更・削除される可能性あり → 定期的な同期、または自前ストレージへのコピーを検討
